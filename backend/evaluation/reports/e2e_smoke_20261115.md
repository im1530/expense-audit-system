## 3. 结论

1. **审核流程在测试库上端到端跑通**：建单 → 上传 → 提交 → 凭证识别 → 规则/风险 → 两级审批 → 支付，状态流转与审批记录一致；
2. **权限边界正确**：经理只能批第 1 级，财务批第 2 级并支付；未授权时凭证识别按设计跳过；
3. **金额不一致能被发现**：票面 34.50 vs 明细 1200 → high / suggest_reject，说明 document_rules → risk → decision 联动有效；
4. **但生产实例（8000 + nginx + HTTPS + Celery）仍未跑过**：本轮用 8001 临时进程、BM25、BackgroundTasks，Celery 队列与 nginx 反代不在覆盖范围内。
