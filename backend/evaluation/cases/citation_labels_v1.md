## 口径

| 字段 | 含义 |
|---|---|
| `core_clause_ids` | 该案例的风险结论**至少**要有其中一条条款支撑；用于**召回率** |
| `optional_clause_ids` | 与案例相关但非必需，引用或不引用都不算错；用于**准确率**分母 |

- **引用准确率（条款级）** = 被引用条款中属于 `core ∪ optional` 的比例
- **引用召回率（案例级）** = 应引用核心条款的案例中，至少引用到一条核心条款的比例
- **检索覆盖率** = 核心条款至少被 BM25 检索到一条的案例比例（检索缺口，不计入模型责任）
- **条件引用召回率** = 核心条款已被检索到的案例中成功引用的比例（衡量模型漏引）

## 涉及条款原文（v1.2）

| 条款 | 原文 |
|---|---|
| 1.1 | 本制度适用于公司全体员工因公发生的费用报销，包括餐饮费、交通费、住宿费、办公费及其他杂费。报销、审批与支付均通过公司报销系统办理。 |
| 1.2 | 报销应遵循真实性、合法性、相关性和及时性原则。报销人应对单据及凭证的真实性负责，不得虚报、重复报销或拆分报销。 |
| 2.1 | 报销单应填写标题、费用明细、费用发生日期、金额及用途说明；一张报销单可包含多条明细，明细应与实际业务一一对应。 |
| 2.2 | 报销应提供合法有效的发票或有效凭证：正式发票抬头为公司全称、纳税人识别号准确，发票金额不得低于对应明细的报销金额；公共交通、网约车、出租车、小额餐饮等无法取得发票的费用，可提供行程单、乘车记录、支付记录、收据等有效凭证。电子发票可上传 JPG、PNG 或 PDF 影像。 |
| 2.3 | 确实无法取得发票或有效凭证的费用（如部分交通票据、行政事业性收费），应填写无票说明并注明原因、金额及佐证材料，由审批人核实。 |
| 2.4 | 一张发票对应多条明细的，应在费用说明中注明分摊方式；发票内容应与费用类别、发生日期、业务事项相符，且票面发票号应与明细填写一致。 |
| 2.5 | 明细未上传发票或有效凭证、未填写发票号且未填写无票说明的，系统将提示凭证缺失；审批人应要求报销人补正后再行审批。 |
| 3.3 | 餐饮费单次限额为：员工工作餐 200 元，加班餐费 150 元，业务招待餐 2000 元。业务招待餐应在费用说明中注明客户名称、招待事由及人数。 |
| 3.4 | 住宿费按实际住宿天数报销，单次限额为：商务酒店 3000 元，快捷酒店 1000 元。因会议、客户指定或一线城市差旅确需入住商务酒店的，应在费用说明中注明原因。 |
| 3.5 | 办公费单次限额为：办公耗材 500 元，打印复印 200 元，文具用品 300 元。采购办公用品应在费用说明中注明用途及使用部门。 |
| 3.7 | 单条明细金额超过所属类别单次限额的，系统将给出风险提示；报销人应说明超限原因，审批人应结合业务实际判断是否全额或部分报销。 |
| 4.1 | 报销人应在费用发生之日起 60 天内提交报销单；费用发生日期以发票或有效凭证载明的日期为准。 |
| 4.2 | 超过 60 天提交的，属于跨期报销，系统将给出风险提示；报销人应说明延迟原因，审批人应重点核实费用真实性与未报销情况。 |
| 4.3 | 同一报销人、同一费用发生日期、同一费用类别且金额相同的费用，在 60 天内重复出现的，系统将提示疑似重复报销；报销人应确认是否为两次真实消费，审批人应重点核对。 |
| 7.2 | 不得将同一业务事项拆分为多张单据以规避审批权限或限额；同一事项的多张单据按合计金额确定审批层级。 |
